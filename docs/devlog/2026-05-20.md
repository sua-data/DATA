# 2026-05-20 Devlog

## 오늘 한 작업

- 감성 분석 결과와 요약 결과를 저장하는 방식을 검토했다.
- KR-FinBERT 기반 감성 분석 결과를 화면과 통계에 어떻게 활용할지 정리했다.
- TextRank 기반 요약 결과의 저장 위치와 사용 목적을 확인했다.

## 내가 맡은 작업

- 감성 분석 결과를 뉴스 단위와 이슈 단위에서 어떻게 활용할지 정리했다.
- 요약 결과가 사용자 화면에서 어떤 형태로 보여야 하는지 검토했다.
- 분석 결과 저장 구조에 필요한 필드를 정리했다.

## 문제점

- 감성 분석 결과를 뉴스 개별 결과로만 저장하면 전체 이슈의 분위기를 보여주기 어려웠다.
- 요약 결과 역시 뉴스 단위 요약과 이슈 단위 요약을 구분할 필요가 있었다.

## 해결 방법

- 뉴스 단위 분석 결과와 이슈 단위 집계 결과를 나누어 생각했다.
- 감성 분포는 일별 이슈 분석 결과에서 활용할 수 있도록 구조를 정리했다.
- 요약 결과는 사용자가 빠르게 이슈 흐름을 이해할 수 있도록 주요 결과에 포함하는 방향으로 정리했다.

## 배운 점

- AI 분석 결과는 모델 출력 그대로 저장하는 것이 아니라 서비스 목적에 맞게 재구성해야 한다는 점을 배웠다.
